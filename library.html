Skill or MCP server

A skill is a folder of instructions, and sometimes scripts, that the agent reads when a task calls for it. An MCP server is a small program that gives the agent new tools, such as a search it can run or an app it can reach.

Reviewed or listed

Reviewed entries are the ones the research kits install. We pinned a version and read the files. Listed, not reviewed means we confirmed the project exists, has a license, and is maintained, but haven't read it line by line. Read it before you use it.

Which data

If an entry stays on your computer, the data rules of your model apply: a local model can work with any data class. If it sends requests outside UF, use it with open data only, even with a local model. Data rules
