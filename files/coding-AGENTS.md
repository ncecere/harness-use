# Project instructions

## Commands

- Install: `REPLACE: e.g. npm install`
- Run tests: `REPLACE: e.g. npm test`
- Lint and format: `REPLACE: e.g. npm run lint`

## How to work

- Make small, focused changes. One task at a time.
- Before editing, explain the plan in a few lines.
- After editing, run the tests and report the result.
- Don't add new dependencies without asking.
- Don't commit, push, or change git history. The human reviews and commits.

## Code style

- Follow the existing style in the file you're editing.
- Prefer clear names over comments. Comment only non-obvious decisions.

## Boundaries

- Never read or print `.env` files, keys, or credentials.
- Don't edit files under `REPLACE: e.g. vendor/ or generated/`.
