Glossary & FAQ

Common questions about cost, data, and choosing tools, followed by plain definitions of the terms the kits use.

01

Common questions

Short answers, with links to the kit that covers each one in full.

How much does this cost?

Every UF student, faculty member, and staff member gets a $100 monthly credit for NaviGator's local models. It resets at the start of each month, and personal keys are valid for one year. Cloud models are billed to a Toolkit team with a UFIT billing ID.

Use is counted in tokens. In our example runs, a quick lookup used about 30,000 input tokens and extracting one table from a long PDF used about 5 million, because the agent re-read the document many times. To see what you've used, open NaviGator AI Toolkit and select your key's Key ID.

To use less: save converted documents to files and point the agent at the part you need, turn off MCP servers you aren't using, and start a new session for a new task.

Can I use these tools with sensitive or restricted data?

Yes, with NaviGator's local models and a workspace with no outside connections. Kit 01 sets that up and tests it. Anything that searches the web or calls an outside service (web search, PubMed, many MCP servers) is for open data only, even with a local model.

The model's approval doesn't change where your data may be stored or what your IRB protocol and data agreements say. If you're unsure, ask your unit's data steward.

Is Microsoft 365 Copilot approved for sensitive data?

No. Use Microsoft 365 Copilot with open data only. For sensitive or restricted data, use NaviGator Chat with a local model. Kit 30 matches office tools to data classes.

Which model should I use?

The kits use meta-muse-glimmer-30b for research and gpt-oss-120b for coding. Both are local, so they work with any data class. Agents need a model that handles tool calls well; larger models usually do better on long, multi-step tasks. The NaviGator model list shows every model and its approved data classes.

OpenCode, OpenCode Desktop, or Pi?

OpenCode asks before commands and web access, has separate Plan and Build agents, and has a desktop app. It's the easier start, and the better choice when you want approvals. OpenCode Desktop is the same agent in a window, if you'd rather not work in a terminal. Pi is small and easy to extend. It doesn't ask before tool calls, so you limit what it can do by choosing its tools when you start it.

Where do my prompts and files go? Are they used for training?

Requests to local models go to UF datacenters. Requests to cloud models go to Microsoft, Amazon, or Google under UF agreements that don't allow training on your data. Tools that search the web, fetch pages, or query outside databases send those queries to the outside service. Sessions are saved on your computer, and they include what the agent read.

How do I know the agent's answer is right?

Check it against the source. Ask for scripts instead of answers worked out in the model's head, ask the agent to count what it produced, and verify citations against PubMed or Crossref. The worked examples show where each check caught a real mistake.

Does this work on Windows?

OpenCode Desktop runs natively on Windows. For the terminal version of OpenCode and for Pi, use WSL2 (Windows Subsystem for Linux) and follow the Linux / WSL steps in each kit.

Do I need to know how to program?

No, but you'll copy a few commands into a terminal during setup. OpenCode Desktop needs the fewest. For research tasks the agent writes the scripts; you should be able to read what it plans to run before you approve it.

Do I need to disclose AI use in my work?

Check your journal's, funder's, and course's policies first. Many require you to say which tool you used and how. Some prohibit AI in certain tasks: NIH, for example, doesn't allow peer reviewers to use generative AI on applications they review. Keep a record of the model, the date, and how you checked the output.

Where do I get help?

For NaviGator accounts, keys, and teams, open a UFIT request or read the NaviGator AI docs. For review search strategies, UF Libraries offers systematic review support. OpenCode and Pi are open-source projects maintained by others; their docs are linked from each kit.

Want an assistant that answers questions from your unit's documents and web pages? That's NaviGator Assistant, which UFIT sets up for departments.
